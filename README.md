# tactile-atlas-gate

`tactile-atlas-gate` 是面向博物馆无障碍内容团队的触觉导览图制版校验工作台。它把制作规格、结构化校样、盲文与版面规则、问题整改、定向复验和独立批准串成可追溯的母版发布闭环，并在本地保存原子 JSON 快照、事件摘要链和不可变发布证据。

## 构建

```text
go build ./cmd/server
```

## 运行

默认监听 `127.0.0.1:19081`：

```text
go run ./cmd/server
```

可使用 `-addr=127.0.0.1:<port>` 指定监听地址，也可设置 `PORT=<port>`（仅端口号会绑定到 `127.0.0.1`）。数据默认写入 `./data`，可用 `-data-dir` 调整。

浏览器打开 `http://127.0.0.1:19081/`，在同一工作台完成以下闭环：

- 冻结前逐字段规格预检，并以匹配当前 `revision` 的 `preflight_digest` 冻结不可变基线。
- 按导览点、路径段、触觉符号、盲文标签和图例五个分区编辑校样，预检全部字段及交叉引用后创建只读快照。
- 查询全量或定向检查历史，对比新增失败、持续失败、转为通过和未覆盖结果。
- 筛选并批量分级、确认、驳回或关闭问题；修订校样保存整改声明、覆盖状态和差异影响摘要。
- 查看字段级版本差异、受影响规则、关联问题和全局复验范围。
- 以最新 `gate_digest` 通过独立批准门禁，发布后逐项核验规格、最终校样、检查运行、关闭问题集合和清单规范摘要。

所有写操作使用 `expected_revision` 防止过期覆盖，并以 `request_id` 保证重放不重复写入。规格预检、校样预检、检查历史、问题筛选、影响矩阵、批准门禁和清单核验均位于现有 `/ui-api/projects/{project_id}` 同源入口下。

## 测试

```text
go test ./...
```

有界端到端自检会启动真实回环 HTTP 服务，走完合格发布流程并主动退出：

```text
go run ./cmd/server -self-check -addr=127.0.0.1:19081
```
